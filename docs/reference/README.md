# Reference implementations

Implementation specs extracted from the riskstore source repositories by the
`/extract-feature` skill. Each document is written so that a session with no access
to the source repos can implement the feature in a new service.

These are shared across every service under `riskstore/`. Point at them from a
service's `CLAUDE.md`; do not copy them into a service repo, or they drift.

Each document carries a provenance header (`Source: <repo> @ <sha>`). A document
whose source repo has moved since extraction is stale — re-extract rather than
trusting citations that no longer resolve.
